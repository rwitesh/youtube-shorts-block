# YouTube Shorts Block

A filter list for **uBlock Origin**. It hides YouTube Shorts.

## What it hides

- The Shorts link in the sidebar and in the mobile bottom bar.
- Shorts shelves on the home, search, hashtag, and channel pages.
- Single Shorts in feeds and search results.
- The Shorts tab on channel pages.
- The Shorts filter chip.
- The Shorts player page.

## Install

1. Open the uBlock Origin dashboard.
2. Click **Filter lists**.
3. Scroll to the bottom. Click **Import…**.
4. Paste this link in the box:

   ```
   https://raw.githubusercontent.com/rwitesh/youtube-shorts-block/main/shorts.txt
   ```

5. Click **Apply changes**.
6. Reload YouTube.

## Update

uBlock Origin updates the list by itself. To update now, click **Update now** in **Filter lists**.

## Remove

Open **Filter lists**. Clear the check box for this list. Click **Apply changes**.

## Notes

- Use uBlock Origin. uBlock Origin Lite does not support all rules in this list.
- YouTube changes its page code from time to time. If a Short shows again, open an issue.

## Tested

Rules were tested on live YouTube pages in desktop and mobile view: home, search, channel, hashtag, and the Shorts player.
